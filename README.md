# BeatForge

BeatForge is a cross-platform beat-making studio built with Expo / React Native, with an Electron Windows desktop shell.

## Product features

- 16 performance pads
- 4-track sequencer (Kick / Snare / Hat / Synth)
- 16 / 32 / 64-step patterns
- Horizontal 32/64-step editing on small screens
- Swing control (0 / 10 / 20 / 30%)
- BPM + tap tempo
- Play / stop / clear / random pattern
- Pattern undo / redo
- Per-track mixer plus master volume
- Pitch / speed control
- Beat-synced loop stems
- Filter, echo, riser and brake FX
- Local project library
- Save / load / rename / delete projects
- Automatic local project saving after edits
- Project persistence for pattern, length, swing, mute state, mixer, BPM, stems and FX
- Android APK GitHub Actions build
- Windows installer + portable build configuration
- CI validation for samples, scheduler and Expo web export

## Architecture

The core studio is shared between Android and Windows. Android runs the Expo / React Native app directly. Windows uses the same exported web UI inside Electron so the sequencing and project model stay aligned across platforms.

Audio samples are generated by `scripts/gen_samples.py` during CI/builds rather than storing generated binaries in source control.

## Development

```bash
npm install
npm run samples
npm run start
```

Android development:

```bash
npm run android
```

Windows development:

```bash
npm run windows
```

Windows installer + portable executable:

```bash
npm run windows:dist
```

Release APK through local EAS configuration:

```bash
npm run build:apk
```

Validation:

```bash
npm run test:scheduler
npm run web:export
```

## Automated builds

Pushes to `main` run CI validation. The Android workflow generates samples, creates the native Android project and builds a release APK artifact. The Windows workflow exports the web app and creates NSIS + portable Windows packages.

## Storage

Projects are stored locally using AsyncStorage. The app does not require a server for normal beat creation or project management.
