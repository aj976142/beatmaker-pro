# BeatForge

AI-powered mobile beat-making studio built with Expo / React Native.

## Project

This repository contains the current BeatForge beat-maker app, including the step sequencer, drum pads, audio sample bank, transport controls, effects, and scheduler.

## Development

```bash
npm install
npx expo start
```

## Roadmap

- Expanded sequencer
